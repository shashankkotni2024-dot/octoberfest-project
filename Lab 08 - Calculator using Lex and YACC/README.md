## 3. Execution Commands (In Order)

### Linux / WSL (Ubuntu)
```bash
# Step 1: Navigate to this directory
cd "Lab Fat Preparation/Lab 08 - Calculator using Lex and YACC"

# Step 2: Run YACC to generate parser source (y.tab.c) and header (y.tab.h)
yacc -d calc.y
# Note: bison -d -y calc.y can also be used interchangeably.

# Step 3: Run Lex to generate lexical scanner (lex.yy.c)
lex calc.l
# Note: flex calc.l can also be used interchangeably.

# Step 4: Compile both C source files using GCC
gcc y.tab.c lex.yy.c -o calc

# Step 5: Run the calculator executable
./calc
```

### Windows (Using WSL or WinFlexBison)
In WSL terminal, run the Linux commands above.
If using WinFlexBison on Windows:
```cmd
win_bison -d -y calc.y
win_flex calc.l
gcc y.tab.c lex.yy.c -o calc.exe
calc.exe
```

## 5. Key Concepts & Viva Notes
1. **How Lex and YACC Work Together**:
   - `yylex()` is called repeatedly by `yyparse()`.
   - Lex reads raw characters, matches regular expressions, sets `yylval` (the semantic value), and returns integer token IDs (defined in `y.tab.h` generated by `yacc -d`).
   - YACC builds the parse tree using bottom-up LALR(1) parsing, executing semantic actions (`$$ = $1 + $3;`).
2. **Precedence and Associativity Directives in YACC**:
   - `%left '+' '-'`: Left-associative binary operators.
   - `%left '*' '/'`: Declared below `+` and `-`, hence higher precedence.
   - `%right UMINUS`: Unary minus has highest precedence and associates to the right.
3. **Semantic Values**:
   - `$$`: Value returned by the LHS non-terminal.
   - `$1`, `$2`, `$3`: Semantic values of the 1st, 2nd, and 3rd symbols on the RHS of the production rule.
4. **Error Handling**:
   - `yyerror(char *s)` is invoked whenever a grammar rule cannot be matched.
